# Agendador de Tarefas

API backend para gerenciar tarefas agendadas, desenvolvida com Java 17 e Spring Boot.

O código inclui operações para criar tarefas, consultar tarefas por usuário ou período, atualizar dados e status de notificação e excluir tarefas.

## Tecnologias

Java 17, Spring Boot, Spring Web, Spring Data MongoDB, Spring Security, JWT, Gradle e Docker.

## Status

Projeto em desenvolvimento. A documentação de execução e os exemplos de requisições ainda estão em preparação.
